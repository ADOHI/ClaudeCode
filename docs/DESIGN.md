# 레벨 디자인 명세 — 루미나 학원도시

이 문서는 생성기가 *무엇을, 어떤 순서로, 왜* 배치하는지 정리한 명세다. 코드 위치는 `src/core/*`.
기술 배경과 출처는 [RESEARCH.md](./RESEARCH.md)에 있다.

## 1. 세계관 → 공간 문법

**루미나 학원도시**는 지름 약 1km의 인공섬이다. 학원 4곳과 생활 구역 8곳이 섬 중앙의 **센트럴 스파이어**를 둘러싼다.

| 구역 | 정체성 (구역 배너 문구) | 가로 문법 (텐서 기저) | 대표 규칙 |
|---|---|---|---|
| 중앙 행정구 | 모든 대로가 모이는 곳 | 방사형 | 7갈래 방사 대로가 소실점으로 모임, 원형 광장, 헤일로 스파이어 |
| 아케이드 상점가 ×2 | 게임센터 불빛과 크레페 냄새 | 중앙을 향한 격자, 생활가로 38m | 코너 = 편의점, 흐름 높은 필지 = 게임센터, 관통 골목 일부를 아케이드 지붕으로 |
| 기숙사·주거구 ×2 | 빨래줄과 고양이 | 격자 + 약한 노이즈 회전 | 안뜰, 빨래줄, 고양이 급식소, 시계탑 랜드마크 |
| 성 루미에르 여학원 | 종탑과 장미 정원 | 중앙을 향한 격자 | 성당, 장미 온실, 벚나무 중정 |
| 아르케 공과학원 | 안테나와 서버 소음 | 중앙을 향한 격자 | 슈퍼컴퓨터동, 드론 발착장, 안테나 시계탑 |
| 레드라인 자유학원 | 낙서와 오토바이 | 격자 + 노이즈 | 차고, 고철 야적장, 낙서 세력권, 라이벌 국경 |
| 스텔라 예술학원 | 노래하는 계단 | 중앙을 향한 격자 | 콘서트홀 돔, 야외 원형무대 |
| 청해 항만구 | 컨테이너 미로와 크레인 | 해안 접선장 | 컨테이너 미로, 갠트리 크레인, 등대 |
| 구시가지 재개발구역 | 숨을 곳이 많다 | 강한 노이즈 회전 | 막다른 골목 50%, 공사장(틈새 하나), 미완의 타워 |
| 미라이 중앙공원 | 세계수가 내려다보는 호수 | 방사형 | 호수 + 세계수 언덕 + MST·순환 산책로 |

구역 배정은 **제약 점수 최적화**로 정한다(`districts.js`). 단항 선호(중심거리, 해안, 하천)에 더해 다음 쌍대 제약을 쓴다.
- 학원끼리는 각도상 멀리 떨어진다.
- 자유학원은 폐허 옆에 둔다.
- 라이벌(자유학원 ↔ 여학원)은 약 280m 거리로 국경을 맞댄다.
- 상점가 두 곳은 서로 떨어뜨린다.

## 2. 파이프라인 (14단계, 단계마다 독립 RNG)

| # | 단계 | 입력 → 출력 | 파일 |
|---|---|---|---|
| 1 | 섬 지형 · 하천 | 시드 → 해안선(만 포함), 곡류 하천, 거리장 | `terrain.js` |
| 2 | 구역 배치 | 포아송 + 로이드 + 제약 점수 → 왜곡 가중 보로노이, 캠퍼스/공원 코어 | `districts.js` |
| 3 | 텐서장 가로망 | 구역 기저장 블렌딩 → 간선 · 진입대로 · 해안도로 · 생활가로, 래스터, 교차점 | `roads.js` |
| 4 | 블록 · 관통 골목 | 연결요소 → 긴 블록에 골목(일부 아케이드, 일부 막다른 골목) | `blocks.js` |
| 5 | 둘레형 필지 분할 | 블록 OBB → 외곽 접도 필지 + 안뜰 + 3.5m 통로, 접도 위계 판정 | `blocks.js` |
| 6 | 도로 흐름 · 랜드마크 비스타 | 4m 도로 그래프 흐름 → 용도 배정용 흐름, 비스타 점수로 랜드마크 필지 | `analysis.js`, `city.js` |
| 7 | 용도 배정 · 건물 | 필지 특징 → 프로그램 가중 선택 → 매싱/파사드/옥상 문법 | `buildings.js`, `city.js` |
| 8 | 학원 캠퍼스 문법 | 축선 문법 + 점수 기반 위치 탐색 + 담장(정문·후문·개구멍) | `campus.js` |
| 9 | 공원 문법 | 호수, 세계수 언덕, 명소, MST+사이클 산책로 | `park.js` |
| 10 | 모노레일 환상선 | 역 각도순 Catmull-Rom 루프 + 중앙 지선, 고가 밑 클리어런스 | `rail.js` |
| 11 | 마이크로 규칙 | 가로등·가로수·정류장·자판기·주차·횡단보도·벚꽃길·낙서 경사·빨래줄 | `props.js` |
| 12 | 흐름 · 아이소비스트 분석 | 2m 보행 비용장 → 보행 흐름, 메인 동선, 숨김도, 우회거리 | `analysis.js` |
| 13 | 의도 레이어 | 표지판, 국경, 옥상 루트, 전망점, 특수 비밀, 자물쇠/열쇠, 숨김 비밀, 막다른 길, 리듬, 흔적, 고양이 | `intent.js` |
| 14 | 지표 | 커버리지, 가시율, 숨김도, 흔적 연결률, 점수, 행동 기술자 | `metrics.js` |

**결정론과 국소 안정성:** `RNG.fork(label)`로 단계마다 스트림을 나누고, 필지·블록 RNG는 좌표 해시로 분기한다. 상점 하나의 규칙을 바꿔도 지형이나 다른 블록은 바뀌지 않는다.

## 3. 분석 필드 정의

모든 의도 규칙은 아래 필드만 근거로 쓴다. 조감 모드의 **분석 오버레이**로 각 필드를 볼 수 있다.

| 필드 | 해상도 | 정의 |
|---|---|---|
| 보행 비용 `cost2` | 2m | 도로 1.0, 골목 1.2, 공터/잔디 1.45. 높이 0.9m 이상 고체와 물은 통행 불가 |
| 보행 흐름 `flow` | 4m | 거점(hub) 약 50개의 모든 쌍 최단경로 통과 횟수를 가중 누적한 뒤 로그 정규화. 근사 매개중심성(space syntax의 choice) |
| 메인 동선 `isFlow2` | 2m | 흐름 상위 16% |
| 숨김도 `hidden` | 2m | 1 − min(1, 보이는 관찰자 수 / 7). 관찰자는 메인 동선 위 약 14m 간격 600–1400명, 72방향 120m 레이, 1.7m 이상 고체에서 차폐 |
| 우회거리 `detour` | 2m | 메인 동선으로부터의 보행 측지 거리 (다익스트라 다중 소스). `detourPrev`는 동선 쪽 경로 |
| 위요도 `enclosure` | 2m | 반경 12m 안에서 16방향 중 막힌 방향 비율 |
| 볼거리 거리 `poiDist` | 2m | 모든 POI·비밀까지의 보행 측지 거리 |

## 4. 의도 규칙 상세

### 4.1 밀도 리듬 `intent.rhythm`
- 목표: 메인 동선 위 모든 셀에서 `poiDist ≤ 6 m/s × 8 s = 48m` (`PACING`).
- 알고리즘: 최원점 삽입. ① 공백이 가장 큰 동선 셀을 찾는다 → ② 걸어서 16m 이내 셀 중 *벽에 붙고 차도가 아닌* 셀에 구역별 마이크로 POI를 놓는다 → ③ 국소 다익스트라로 거리장을 갱신한다 → 반복.
- 결과 예시(seed `lumina`): 커버리지 94% → 100%, 최대 공백 89m → 48m, 추가 POI 17개.
- 확장: 시간 단위로 정의했으므로 모노레일 구간은 열차 속도로, 파쿠르 구간은 루트 속도로 바꿔 계산할 수 있다.

### 4.2 숨김 보상 `intent.secret`
- 후보: `hidden ≥ 0.72`, `10 ≤ detour ≤ 160m`, 차도가 아님, `enclosure ≥ 0.3`.
- 점수: `0.45·hidden + 0.3·enclosure + 0.25·min(1, detour/60) + 구역 보너스(폐허 +0.08, 항만 +0.05)`.
- 구역별 쿼터와 최소 간격(폐허 24m … 중앙 40m)으로 분포를 맞춘다.
- 유형은 맥락으로 정한다. 캠퍼스는 학원 불가사의, 자유학원 반경 220m는 낙서 태그, 항만은 밀수품 상자, 폐허는 잊혀진 기록/고양이, 그 외는 고양이/보물.
- 공개 방식 태그: 모퉁이 뒤(삼각형 규칙) / 움푹한 구석 / 막다른 길 / 옥상 루트 끝 / 보이지만 닿지 않음 / 랜드마크 정상 / 미로 막다른 칸 / 펜스 틈새 / 잠긴 문 너머.

### 4.3 호기심의 인력: 미끼와 흔적 `intent.crumb`
- 비밀에서 `detourPrev`를 따라가면 메인 동선까지의 최단 이탈 경로가 나온다.
- **미끼**: 경로가 동선을 떠나는 지점(2번째 셀)에 둔다. 동선에서 보이도록 놓는다. 유형별로 고양이 / 푸른 도깨비불 / 바닥 스프레이 화살표 / 반짝임.
- **흔적**: 미끼 이후 6m 간격으로 비밀 4m 앞까지 둔다. 유형별 색: 발자국, 도깨비불, 스프레이, 종이, 끌린 자국.

### 4.4 옥상 루트 `intent.rooftop`
- 그래프 노드는 평지붕(5–36m, 45m² 이상)이다. 간선은 두 종류다.
  - 점프: 간극 ≤ 3m, 높이차 ≤ 3.5m (점프 1.6m + 매달려 오르기 3.6m)
  - 판자: 간극 3–8.5m, 높이차 ≤ 2m. 크루스칼처럼 컴포넌트끼리만 잇는다. 판자는 디자이너가 의도한 연결이다.
- 크기 4 이상인 컴포넌트가 루트가 된다.
  - 입구: 가장 낮은 지붕의 **골목면이나 뒷면**에 비상 사다리를 둔다.
  - 경로 지붕마다 코인을 둔다.
  - BFS 최원점에 보상을 둔다.
- **보이지만 닿지 않음**: 메인 동선 위 점에서 목표 지붕 가장자리가 보이면(높이를 고려한 시선 검사) 보상을 그 가장자리로 옮기고 시선선을 기록한다.

### 4.5 자물쇠와 열쇠 `intent.gate`
- 대상: 상업·주거·폐허·중앙 구역의 안뜰 필지. 통로가 있는 블록을 우선한다.
- 문: 3.5m 통로의 안쪽 끝, 또는 안뜰에서 동선까지 경로 중 주변 통행셀 수가 가장 적은 '최협점'에 둔다.
- 열쇠: 같은 구역, 문에서 보행 60–220m, 숨김도 ≈ 0.55(너무 숨기지 않음), 위요도가 높은 곳.
- 보상: 안뜰의 '비밀 동아리방의 상자'.

### 4.6 막다른 길 `intent.deadend`
- 가로망 끝점 중 다른 길에 잇지 못한 곳, 재개발구역의 막다른 골목, 하천에 막힌 길을 모두 수집한다.
- 16m 안에 POI나 비밀이 없으면 보상을 놓는다. 하천변은 전망 벤치, 숨김도 0.6 초과는 비밀, 나머지는 작은 신사/자판기.
- 지표 `deadEndCoverage`는 항상 100%여야 한다.

### 4.7 길찾기 단서
- **랜드마크 비스타** `intent.landmark`: 후보 필지에서 72방향 레이를 쏴 도로 위로만 뻗는 길이의 제곱평균을 구하고, 구역 시드와의 거리로 감쇠한다. 최대인 필지에 랜드마크를 세운다.
- **방향 표지판** `intent.signpost`: 간선 2개 이상이 만나는 교차점(110m 간격)에 둔다. 스파이어와 가장 가까운 랜드마크 2곳을 가리킨다.
- **전망점** `intent.vantage`: 학원 본관 옥상(뒷면 비상계단), 시계탑 발코니, 미완의 타워 정상, 옥상 루트 정상.

### 4.8 서브컬쳐 트로프 규칙
- **학원 7대 불가사의** `intent.wonder`: 캠퍼스 안 숨김도 상위 지점 5곳 + 숨김 비밀 일부. 학원마다 고유한 괴담 목록이 있다.
- **전설의 나무** `intent.legendtree`: 캠퍼스에서 숨김도가 가장 높으면서 주변이 트인 녹지(위요도 ≤ 0.5)에 둔다.
- **옥상**: 학교 본관 옥상은 펜스와 계단실이 있는 전망점이다.
- **구교사**: 정문에서 가장 먼 곳에 둔다. 담장 **개구멍**은 구교사/체육관 뒤에 낸다.
- **경쟁 국경** `intent.border`: 라이벌 구역 경계를 지나는 도로 셀에 바리케이드(가운데 한 칸은 통과 가능)와 검문소를 둔다.

## 6. 튜닝: 코드를 고치지 않고 표를 고친다

- `config.js › DISTRICT_TYPES`: 구역별 가로 간격(`minorSep`), 텐서 기저(`field`), 노이즈 회전, 골목 확률, 막다른 골목 비율, 필지 크기, 층수.
- `buildings.js › ZONING`: 구역별 `[프로그램, 필지특징 → 가중치]` 표. 예: `['convenience', (l) => (l.corner ? 4 : 0.2)]`는 코너 필지를 편의점으로 만드는 규칙이다.
- `buildings.js › PROGRAMS`: 층수, 셋백, 매싱, 옥상 문법, 차양/간판, POI 등급.
- `config.js › MICRO_POIS`, `SECRET_TYPES`, `RULES`(인스펙터·규칙 패널 문구).
- `intent.js › PACING`: 리듬 목표(속도 × 초).
- `generator.js › DEFAULT_PARAMS`: 품질 다양성 탐색이 변이시키는 유전자(`density`, `alleys`).

- **JSON 스키마** (`export.js`, 조감 모드의 "엔진 임포트용 JSON 복사"):
  - 좌표: 미터, Y-up, 원점 = 섬 중심.
  - `rot`: 로컬 +x(u)축의 월드 각도. x→z 방향, 라디안. three.js에서는 `rotation.y = -rot`이다. Unity(왼손 좌표계)에서는 z를 반전한 뒤 yaw = `rot`(도 단위로 변환)을 쓴다.
  - `y`는 바닥 높이다. 중심 높이가 아니다.
  - 엔티티마다 `shape/kind/cat/rule/why/solid`가 있다.
- **Unreal 5.7+/5.8 PCG**: 엔티티를 Point Data로 읽고 `kind`로 메시 셋을 고른다(Static Mesh Spawner). 도로 폴리라인은 Spline으로 받는다. 5.8의 '재생성해도 유지되는 수동 편집'과 함께 쓰면 "생성 + 디자이너 덧칠" 워크플로가 된다.
- **Unity**: ScriptableObject로 임포트하고 `kind` → 프리팹 매핑, `solid`면 콜라이더. 도로는 Spline 패키지로 받는다.
- **충돌/내비**: `collision.js`의 2층 높이장(floor + deck)은 NavMesh 베이크 전에 빠르게 검증하는 용도다. 사다리는 `climb {x,z,top,nx,nz}`, 잠긴 문은 `gate` id로 열쇠와 연결된다.

## 8. 알려진 한계와 다음 단계

- 분석 해상도가 2m라서 1.5m 미만 틈은 분석상 막힌 것으로 볼 수 있다. 탐험 충돌은 1m라 실제로는 지나갈 수 있는 곳이 있다. → WebGPU 1m 분석으로 개선할 계획이다.
- 가시성은 지상 1.6m 눈높이 2D 레이캐스트다. 높이를 고려한 검사는 랜드마크·티저 시선에만 쓴다.
- 건물 내부와 지하는 없다. 서브컬쳐 학원물의 핵심인 교실·동아리방 내부는 다음 단계에서 그래프 문법(Dormans)으로 생성할 계획이다.
- 리듬 목표값(8초)과 숨김 임계값은 플레이테스트로 보정해야 하는 파라미터다.
